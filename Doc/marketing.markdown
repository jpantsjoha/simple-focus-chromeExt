# Simple Focus Mode v0.4.0 - Release Notes & Marketing Assets

## 🚀 Features & Updates
*   **High-Contrast Dark Mode**: A completely redesigned theme using solid, opaque colors (`#000000` / `#1c1c1e`) ensures perfect visibility in any lighting condition. No more hidden buttons or low-contrast text.
*   **Improved UI Layout**: The Settings button has been moved to the footer for better accessibility and a cleaner header.
*   **Enhanced Reliability**: Fixed invisible icons for the "+1 Minute" and "Skip Break" features in dark mode.
*   **Performance**: Streamlined the codebase by removing experimental features, ensuring the extension remains lightweight and privacy-focused (100% Local).
*   **Visual Polish**: Enforced consistent Apple-style iconography and spacing across all views.
